## Abstract

The Sustainability Household Usage and Building Monitor is a Java-based
application designed to monitor household electricity, water, and waste
usage. The system helps users understand their resource consumption and
provides suggestions for reducing unnecessary wastage.

## Setup and Execution

1. Install Java JDK.
2. Clone this repository.
3. Open the src folder.
4. Compile the Java program.
5. Run the Main class.
